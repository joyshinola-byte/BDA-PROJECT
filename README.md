MiniSparkRDD

MiniSparkRDD is a Python-based implementation of Apache Spark's Resilient Distributed Dataset (RDD) concepts. This project demonstrates how data can be loaded, transformed, and processed using a custom RDD framework without relying on Apache Spark.

Features

- Load CSV datasets
- Custom RDD implementation
- Filter and Map transformations
- Simple DAG execution
- Lightweight and easy to understand

Project Structure

- `Data/` – Contains the input dataset.
- `src/` – Source files for RDD implementation.
- `main.py` – Main program to execute the project.

Requirements

- Python 3.x
- VS Code (Recommended)

 How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python main.py
```

 Output

The project reads the dataset, performs RDD transformations such as filtering and mapping, and displays the processed results.

 Technologies Used

- Python
- CSV
- Object-Oriented Programming (OOP)
- RDD Concepts
